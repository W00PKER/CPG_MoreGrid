# Changelog

## 1.0.0

- Added rotatable circuit transformer with up to 30 total integer turns.
- Added primary/secondary stray losses, magnetizing/core-loss branch and thermal output.
- Added one-shot configurable I²t cartridge fuse.
- Added piecewise-linear latching SCR thyristor.
- Added non-rechargeable zinc-carbon dry-cell pack with SOC and internal resistance.
- Added dedicated MoreGrid creative tab and Redstone Blocks tab entries.
- Added English and Korean translations, recipes, item icons and component models.
